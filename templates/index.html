LOCAL EXTRACT · STRICT TEXT AUDIT · v1.2

科技期刊图件提取与 AI 校对

Word 原稿仍由本机 Microsoft Word 提取；只有你点击 AI 校对时，对应的“原稿图 + 重制图”才发送到所选视觉模型。Gemini 已移除。默认优先使用阿里云百炼 Qwen，网络/额度失败时可自动切到 Groq、OpenRouter Free。

01

作者 Word 原稿

支持 .doc / .docx。第一作者与文章标题从正文识别，不信任文件名。

0 个 Word
02

重制图文件夹

支持 PDF / JPG / JPEG / PNG。程序按“正文第一作者 + 图号”配对；例如 艾晶-图3.pdf。单篇文章时，仅有 图3.pdf 也能配。

0 个 PDF/JPG/PNG
03

AI 服务与 API Key

推荐只先配“阿里云百炼”。自动模式的降级顺序固定为：百炼 → Groq → OpenRouter Free；未配置 Key 的服务会自动跳过。Key 不写进网页源码，勾选保存时优先放进 Windows 凭据管理器。

自动模式只在 API/网络/额度失败时切换，不会因为某个模型给了 PASS/FAIL 就再调用第二个模型。
精确模式会多调用一次 AI：第一阶段机械抄录两图文字，第二阶段再核对结构。只要文字库存无法完全对齐，后端禁止自动 PASS。
① 阿里云百炼 Qwen未配置

主服务。默认建议 qwen3.7-plus 做精确校对；也可切 qwen3.8-flash / 旧版 VL Flash。

② Groq Qwen未配置

高速备用。支持两图输入与 JSON，免费计划额度以 Groq 控制台为准。

③ OpenRouter Free未配置

最后兜底。openrouter/free 会在当时可用的免费视觉模型中路由，稳定性与判错尺度可能波动。

04

提取并自动配对

这一步不调用 AI。继续使用 v0.8 已验证的“Word 对象优先”提取逻辑，再将重制 PDF/JPG 渲染成图并按作者+图号配对。

05

原稿 ｜ 重制图 ｜ AI 结论

FAIL / REVIEW 会列出具体位置、原稿内容与重制内容；每张结果同时记录实际使用的服务与模型。
